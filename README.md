# Fields Manager

Ứng dụng Streamlit quản lý sân bóng. Tab đặt sân và hủy sân đọc, ghi dữ liệu từ các tệp JSON trong thư mục `Data`.

## Cài đặt và chạy

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run main.py
```

Tab Sân bóng và Thanh toán hiện là vị trí chờ tích hợp các module tương ứng.
